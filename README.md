# AI Discord Bot

A lightweight Discord bot powered by the OpenAI API.

It supports:
- `!ai` chat replies in-channel
- direct `@mention` replies
- a placeholder `!img` command with cooldown + “coming soon” response

## Requirements

- Node.js 18+
- A Discord application + bot token
- An OpenAI API key

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file in the project root:
   ```env
   DISCORD_TOKEN=your_discord_bot_token
   OPENAI_API_KEY=your_openai_api_key
   ```
3. Start the bot:
   ```bash
   node index.js
   ```

## Bot behavior

### Chat triggers

The bot replies when either of these is true:
- Message starts with `!ai`
- Message directly mentions the bot

It ignores `@everyone` / `@here` triggered contexts to avoid noisy mass-mention behavior.

### Conversation context

When generating a response, the bot fetches recent channel history (up to 40 messages), includes text + attachment URLs, and sends that as context to OpenAI.

### Image command (`!img`)

`!img <prompt>` is currently text-only and does **not** generate images yet.

Current guardrails:
- Prompt length capped
- Per-user cooldown (25 seconds)
- Friendly “coming soon” response generated by OpenAI

## Environment variables

- `DISCORD_TOKEN`: Discord bot token used for login
- `OPENAI_API_KEY`: API key for OpenAI responses

## Notes

- The project is currently plain Node.js (CommonJS), with `index.js` as the entrypoint.
- Default `npm test` is not configured yet.
